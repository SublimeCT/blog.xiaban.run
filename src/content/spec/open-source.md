# 开源项目

## 热门项目

### 深渊吞噬 VOID

::github{repo="SublimeCT/hole.io.webrtc"}

开源免费的 `hole.io`(黑洞大作战) 类网页小游戏, 支持联机

- 道具：地图上会刷新出 🧲磁铁（吸得更快）、🔍放大镜（把周围建筑缩小方便吞）、🍔汉堡（一口直接加分）、👣脚印（从天而降的脚印），还有比较搞心态的"🍺啤酒杯"和"💩便便陷阱"
- 技能：Q 加速冲刺、E 直接升一级、R 自爆把其他黑洞炸掉

- 联机：最多 5 人对战, 但目前 guest 端会比较卡
- 单机：与两个 bot 对战

### Swagger MCP

::github{repo="SublimeCT/swagger-prompts-mcp"}

- 🚀 **快速解析** - 秒级解析大型 Swagger/OpenAPI 文档
- 📝 **中文提示** - 生成完整的中文 API 文档提示词
- 🔗 **引用解析** - 自动解析所有 `$ref` 引用
- 🌍 **路径前缀** - 自动识别并添加 `servers[0].url` 路径前缀
- 📦 **双重模式** - 支持 MCP 服务器
- 🎯 **智能提示** - 生成适合 AI 模型的 JSON Schema 格式
- 🔐 **认证支持** - 支持 Bearer Token 和基本认证（用户名/密码）
- 💾 **本地下载** - 一键下载 Swagger JSON 到本地文件

## 技术栈

我的开源项目涵盖了以下技术栈：

- **前端**: JavaScript, TypeScript, Vue 2/3, React, Angular

- **后端**: Node.js, Egg.js
- **数据库**: MongoDB
- **WebAssembly**: Rust, wasm-pack
- **桌面应用**: Electron
- **构建工具**: Vite, Webpack
- **其他**: Tampermonkey, GraphQL, WebRTC
